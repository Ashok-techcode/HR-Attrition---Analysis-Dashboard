# HR-Attrition---Analysis-Dashboard

## HR Analytics Dashboard

This project provides insights into employee attrition using interactive visualizations. It helps organizations identify key factors influencing employee turnover such as age, salary, job role, and job satisfaction.

### Key Insights
- Highest attrition observed in certain job roles
- Younger employees show higher turnover
- Lower salary ranges correlate with higher attrition


### Tools Used
- Power BI
- Sql Server
- Excel


### Business Problems
- High employee attrition leading to increased hiring and training costs  
- Lack of visibility into factors driving employee turnover  
- Difficulty identifying high-risk groups based on age, salary, or job role  
- Low job satisfaction impacting productivity and retention  
- Ineffective compensation strategies contributing to employee exits  
- Limited insights into how education and background influence attrition  


###  Business Value
- Helps reduce employee turnover  
- Improves workforce planning  
- Identifies high-risk attrition groups  
- Supports better compensation strategies  
- Enhances employee satisfaction


### 📌 Conclusion
This dashboard transforms HR data into actionable insights, helping organizations proactively manage employee attrition and build a more stable workforce.
